# タスク: トゥーン影の一時無効化

## 結果

PMX由来を含むMMdlマテリアルで`UseToonMap=false`を強制し、トゥーン影を一時的に無効化した。

## 変更

- PMX変換時、全マテリアルの`UseToonMap`をfalseに設定。
- MMdl読み込み時、既存`.mmat`の値に関係なくGPUへfalseを渡す。
- X系の既存設定、シェーダー、テクスチャ、形状、アニメーションは変更していない。

## 検証

- Debug x64: 0エラー、0警告
- Release x64: 0エラー、0警告
- BOMチェック: 215ファイルすべてOK
- 実機確認: ユーザー確認待ち

## 次の判断

実機で黒い部分が消えれば、原因はトゥーン影である可能性が高い。消えなければ、ベーステクスチャ、通常ライティング、スフィアマップ、または描画状態を追加調査する。
