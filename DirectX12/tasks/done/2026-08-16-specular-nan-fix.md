# タスク: 無効なスペキュラー計算によるNaNの修正

## 結果

スペキュラー色または強度が無効なマテリアルでは、スペキュラー計算を実行せず`specularB=0`とするように修正した。

## 原因

X由来マテリアルは`Specular=(0,0,0)`、`SpecularPower=0`だったが、シェーダーが常に`pow()`を実行していた。RenderDocで`specularB=NaN`を確認し、NaNがカラー計算に混入して黒化していた。
