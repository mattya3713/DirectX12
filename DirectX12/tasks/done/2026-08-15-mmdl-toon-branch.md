# タスク: MMdlマテリアルのトゥーン使用分岐

## 結果

PMX/X由来のマテリアルで、トゥーン計算を使用するかを`UseToonMap`として保存・伝搬し、シェーダーで分岐するようにした。

## 実装内容

- `RuntimeFormat::MmatData`と`.mmat`に`UseToonMap`を追加。
- 旧MMAT version 2は読み込み時に従来互換としてトゥーンパスの有無から判定。
- PMXは有効なトゥーンテクスチャがある場合のみ`true`。
- Xは`false`。
- `Model::Material`、GPUマテリアル、MMdlActorまでフラグを伝搬。
- PMXピクセルシェーダーは`false`ならトゥーンテクスチャをサンプリングせず、白いトゥーン値を使用。
- MMdlのトゥーン未指定時のテクスチャも白に統一。

## 検証

- Debug x64: 0エラー、0警告
- Release x64: 0エラー、0警告
- BOMチェック: 215ファイルすべてOK
- 実機の見た目確認: 未実施

## 学習ポイント

`UseToonMap`は「トゥーン画像が無いときの代替画像」ではなく、「マテリアルのライティング方式そのものを選ぶフラグ」。変換時に決め、GPU定数バッファを経由してシェーダーが使い分ける。

## 備考

Codexの最終レポートは前回タスクの内容を返したため、今回の結果は実ファイル差分と独立ビルドで確認した。
