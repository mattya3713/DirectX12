# tasks/done/

Completed tasks are moved here from `tasks/current.md` once reviewed and accepted,
named `YYYY-MM-DD-short-slug.md`. This is a history of what was delegated to Codex and
completed — not a changelog (see `DESIGN.md` at the repo root for the actual
architecture/decision record, and `devlog/` for investigation write-ups).

This file exists only so the empty folder is tracked by git; delete it once the first
real task lands here, if you'd rather keep the folder clean.
